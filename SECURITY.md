# Güvenlik Politikası

## Desteklenen sürüm

Güvenlik güncellemeleri üretimde çalışan güncel `main` sürümüne uygulanır.

## Açık bildirme

Güvenlik açığı, kimlik doğrulama sorunu, ödeme riski veya veri sızıntısı şüphesini herkese açık GitHub issue olarak paylaşmayın.

Bildirimi depo sahibi [@Methefor](https://github.com/Methefor) ile GitHub üzerinden özel olarak paylaşın. Rapora şunları ekleyin:

- Etkilenen sayfa, API rotası veya bileşen
- Sorunun tekrar üretim adımları
- Olası etki
- Varsa ekran görüntüsü veya güvenli kanıt

Secret, gerçek ödeme verisi veya müşteriye ait kişisel veriyi rapora eklemeyin.

## Müdahale

Doğrulanan kritik açıklar öncelikle sınırlandırılır, ardından düzeltme hazırlanır ve üretim ortamında doğrulanır. Gerekli durumlarda ilgili anahtarlar yenilenir ve etkilenen entegrasyon kayıtları incelenir.
